# Vogelbingo

Example bird-spotting bingo game for vogelbingo.nl. Static HTML/CSS/JS, hosted on GitHub Pages.

## Development

Just open `index.html` in a browser — no build step.

## Hosting

Deployed via GitHub Pages with a custom domain (see `CNAME`). DNS at the domain
registrar (TransIP) needs to point `vogelbingo.nl` at GitHub Pages — see the
repo's GitHub Pages settings for the required records.
